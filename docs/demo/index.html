Unbounded fluid scaling

Values keep scaling proportionally below the mobile design width and above the desktop design width.

Clamped scaling (v2.4)

Same curve, bounded with $min / $max — the value never leaves [24px, 48px] on any screen.

Bounded spacing

Works per element on shorthand values too, and with one-sided max() bounds.

Unit-preserving scaling with bounds — respects the user's root font size and never exceeds the design range.
